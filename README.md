# Mecânica Clássica I (DF005)

Site da disciplina, no ar em https://apianomorais.github.io/mecanica-classica-i

- Páginas geradas pelos scripts de `ferramentas/`: `python3 ferramentas/pagina_index.py`, `python3 ferramentas/pagina_aulaNN.py`.
- A lista de módulos vive em `ferramentas/molde.py`, e é dela que saem o menu, as setas de navegação e os cartões da página inicial.
- Programas do curso em `codigo/`, com numpy e matplotlib, feitos para rodar no Spyder.
- Widgets interativos em `assets/js/widgets.js`.
